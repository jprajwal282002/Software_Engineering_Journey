1) A variable is a namespace given to a value that is being stored in a memory.

2) Lists - List is like array which stores values or strings in memory at index positions starting from 0.
METHODS - list.append() - adding element to the list at the end
          list.remove() - deleting any particular element from the list
          list.pop() - deleting any element from the list using their index position
          list.insert(index, element) - adds element in the list at desired index position

3) for loop - for loop iterates through each element and perform the repititive task until the desired condition is satisfied.
METHODS - for i in n:
          for i in range(n):
          for i in range(start, stop):
          for i in range(start, stop, step):
